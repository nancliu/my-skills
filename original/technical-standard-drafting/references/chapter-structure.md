## 1. 典型结构总览

```
2 ××（章名）
├─ 2.1 一般规定
├─ 2.2 ××对象/技术域 A     （分专业/分对象章节）
├─ 2.3 ××对象/技术域 B
├─ 2.4 ××对象/技术域 C
├─ 2.5 特殊场景             （特殊场景分列）
│   ├─ 2.5.1 高风险场景一
│   └─ 2.5.2 高风险场景二
├─ 2.6 衔接/接口             （与上级系统、关联方）
└─ 2.7 数据与安全             （收尾章节）
```

各部分编写顺序：先一般规定（总纲），再分专业/分对象章节（主体），再特殊场景（安全底线），再衔接与数据（互联支撑）。

---

## 2. 一般规定（第1节）

承担全章总纲职责，典型条款序列（按需取舍）：

1. **适用范围**：本章规定××的建设/实施技术要求，适用于新建、改扩建及存量工程的××规划、设计与实施。
2. **对象定义与定位**：界定对象范围，明确其在体系中的定位与支撑目标，用"1) 2)"列支撑内容。
3. **总体原则**：定义"应/宜/可"三级语义（此处唯一定义）；分级/分档原则。
4. **差异化原则**：按规模/条件分档差异化确定实施深度（引用确定档位的依据标准）。
5. **建设原则**：共享复用、避免重复建设。
6. **数据接入总要求**：统一接入上级平台，满足与关联方数据互通与协同调用（引用相关文件）。
7. **数据质量与上传/更新周期**：质量要求 + 分档周期。
8. **总体要求**：涉及多专业交叉的总要求（指向专项文件，本章细化特殊场景）。
9. **设备/产品选型原则**：成熟、可靠、易维护，兼顾经济性；特殊条件用替代方案。

> 教训：某条第3条曾附"三级配置要求表"，因与条文定义重复被删除——一般规定里表格承载量化规则才保留。

## 3. 分专业/分对象章节

每个技术域或对象一章，统一两小节结构：

- **×.×.1 功能要求**（或"功能配备"）：功能目标、能力要求、性能指标、数据要素、保存要求。
- **×.×.2 实施要求**（或"设备选型及布设"）：符合的标准/规范引用、规格参数、布设位置与密度、差异化放宽规则、暂缓实施条件。

编写要点：

- 先引用权威文件（实施应符合《××》相关规定），再给本地化细化条款。
- 量化参数（分辨率、精度、间距、准确率、响应时间）必须给数并注明依据。
- 差异化条款逐条给出触发条件，例如：
  - `高等级/大规模对象按本部分规定标准实施`；
  - `低等级/小规模对象可放宽密度、降低等级`；
  - `条件不足且风险低的对象可暂缓……，以共享数据替代`。
- 分档规则适合用表格承载（表：档次 / 实施要求 / 配置要求三列）。

## 4. 特殊场景分列

原则：

- 特殊场景 = 具有独特构造或典型环境特征、存在安全风险或效率问题、需要针对性实施的对象。
- **安全底线类内容按"应"级，不因规模/条件高低减免**，实施深度按风险等级差异化。
- 各场景分列小节，避免混在一起。
- 有专项文件覆盖的场景（如隧道群、特大桥梁），**直接引用专项要求**，不在通用标准重复展开。
- 独立子主题提升为下一级标题（如 2.5.1.1 / 2.5.1.2）。

---

## 5. 衔接/接口章节

当标准对象是更大体系中的组成单元（接入方/协同单元/执行层）时，单列衔接章节：

- **衔接部位要求**：与上级系统/关联方的衔接点应实现覆盖与数据对接。
- **边界要求**：边界处连续监测、数据按规定上传。
- **数据对接**：互通互传、按需调用；接口、交换格式、上传要求指向数据章节。

编写逻辑：以"数据互通、协同调用为核心，优先复用既有资源，减少重复建设"。

---

## 6. 数据与安全收尾章节

统一收口全章数据要求：

- **数据要素与质量**：列出数据要素清单；质量要求指向各专业章指标。
- **传输与周期**：分档传输周期（与一般规定一致）、指定传输通道、分级联网上传。
- **共享交换**：与相关部门及第三方平台共享；数据格式符合相关标准。
- **治理与安全**：质量评价与在线校准机制；传输存储符合网络安全相关规定，保护个人信息。

---

## 7. 建设期与运营期分开

- 建设期一次性内容（设计、建造、施工管控）**不放运营期配置章节**，单独归入"建设/智慧建造"章节。
- 原因：建设期按新建/改扩建一次性投入执行（如 BIM 交付要求），不适用"运营期按规模取舍"的逻辑。
- 运营期章节只处理运营期取舍，避免两类逻辑混淆。

## 8. 示例：某"多源感知"章节

> 以下为真实项目定稿结构（《××数智化升级技术要求》第六部分"多源感知"），展示通用模式的具体映射：

```
2 多源感知
├─ 2.1 一般规定
├─ 2.2 视频监控           （分对象章节：功能配备 + 设备选型及布设）
├─ 2.3 交通流检测
├─ 2.4 交通事件检测
├─ 2.5 交通气象监测
├─ 2.6 特殊路段感知       （特殊场景分列）
│   ├─ 2.6.1 恶劣气象高影响路段感知
│   ├─ 2.6.2 地质灾害频发路段（边坡）感知
│   ├─ 2.6.3 隧道群及特大桥梁感知（2.6.3.1 隧道结构监测 / 2.6.3.2 桥梁健康状态监测）
│   └─ 2.6.4 连续长下坡及避险车道感知
├─ 2.7 路网衔接感知       （衔接章节：互通枢纽区 / 路段边界 / 与骨干路网数据对接）
└─ 2.8 感知数据接入与共享 （数据收尾：要素与质量 / 上传周期与传输 / 共享交换 / 治理与安全）
```

映射关系：一般规定 → 2.1；分对象章节 → 2.2~2.5；特殊场景 → 2.6；衔接 → 2.7；数据收尾 → 2.8。该章"2.6 隧道群及特大桥梁"直接引用安全提升工程专项要求，未重复展开。
