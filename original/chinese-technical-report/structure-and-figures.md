## 1. 章—节—段

| 层级 | Markdown | 要求 |
| --- | --- | --- |
| 章 | `## N. 标题` | 一章一个目的；标题只标议题，不作口号 |
| 节 | `### N.M 标题` | 层级连续，不跳级；下级不重复上级题名 |

**标题不写结论或论断。** 题名只标明讨论对象或工作内容，判断留给正文。

| 不宜作标题 | 宜改为 |
| --- | --- |
| 本阶段不予采用的措施 | 措施边界说明 |
| 手改供给：引擎不消费 | 节点能力供给方式的实测 |
| 暂未纳入正式诊断的规则 | 其余成因规则的处理 |
| 已解决 / 未解决 | 工作进展 / 主要局限 |
| 本报告明确不是 | 报告边界说明 |
| 段 | 正文段落 | **一段一主题**；中心句在段首；后文展开条件、证据、边界 |

正式研究报告每个 substantive 节至少包含：

1. **段**（2～4 句）：判断 → 依据/条件 → 边界或读法  
2. **图或表**（若该节有清单、流程、空间关系或对照数字）  
3. **回指一句**（可选）：如图× / 见表× 所示……

禁止把整节写成「无叙述的裸表」或「只有条列、没有中心句」。条列可作段后补充，不能替代段。

## 2. 何时用图、何时用表

| 内容类型 | 优先 | 示例 |
| --- | --- | --- |
| 流程、分档、范围圈、类—项层级 | **图** | 规则筛选分档、参数闭集 |
| 规则清单、映射、样品证据、KPI 对照 | **表** | 规则清单、硬校验映射、基准 vs 方案 |
| 单点实测、否定边界 | **段**（可加短表） | 某写法不被引擎消费 |
| 队内催办、供料状态 | **不进正文** | 放 README / 文首元数据 |

一张图只表达一个结论；一张表只服务一个问题。图与表不得互相矛盾。

## 3. 图号、表号与文内引用

正式研究报告（定稿目标）使用章内编号：

- 图：`图 3-1`、`图 4-1`（章号-序号）
- 表：`表 3-1`、`表 4-2`

写法（正式研究报告 Markdown）：

```markdown
　　如图 3-1 所示，入库规则收到四档终点，正式自动诊断只跑其中一部分。

\`\`\`mermaid
...
\`\`\`

<p align="center"><strong>图 3-1</strong> 成因规则的筛选与分档</p>

　　正式路径纳入的规则见表 3-1。

<p align="center"><strong>表 3-1</strong> 正式诊断规则清单</p>

| ... | ... |
```

排版规则：

- **段首缩进**：正文段落行首两个全角空格（`　　`）；标题、列表、表格、代码块、引用块不缩进。
- **图题**：图在上、题在下，居中；格式 `<p align="center"><strong>图 N-M</strong> 题名</p>`。
- **表题**：题在上、表在下，居中；格式同上，将「图」改为「表」。
- 先有文内「如图× / 见表×」，再放图或表；避免「悬空图表」。
- 图题 / 表题用中文概括，不写仓库路径；标题不写结论或论断。
- 答辩技术总结可继续用【图ID】图B-x；剪进正式正文时改成上列格式并删口播块。

## 4. 节契约（写节前五问）

借鉴 research-writing 的「契约先于段落」。每节动笔前默答：

1. **本节目的**：读者读完应得到什么判断？  
2. **允许主张**：有哪些已核过的事实/表可写？  
3. **禁止主张**：哪些绝不能写（如无证据的成效断言、试验路径当正式）？  
4. **输入**：真源文件或样品路径是什么？  
5. **校验**：数字、条数、哈希与全文他处是否一致？

答不清则先查真源（知识库章节见 `kb-report-sync.md`），不编占位故事。

## 5. 证据分层（写进正文时的标签习惯）

叙述中区分（可用括号或短句标明，勿伪造）：

| 层级 | 含义 | 写法示例 |
| --- | --- | --- |
| 已有数据 | 表内、样品、实测文件 | 「样品事实袋交通负荷为 1.76」 |
| 用户/队内已确认 | Issue 冻结、台账分档 | 「正式路径只跑已纳入规则」 |
| 按上下文推断 | 需标明 | 「据此可视为同一过饱和范围」 |
| 建议性扩展 | 不进正式结论 | 放局限或附录建议 |

不确定度不得升级：「提示 / 可视为」不得改成「证明 / 已见效」。

## 6. 句段改写策略（来自技术文档 skill）

- 杂乱段 → 提炼中心句，拆成 2～4 短句  
- 跳级标题 → 补层级或上收  
- 说明不清 →「前提 → 做法 → 结果 → 边界」  
- 句子过长 → 拆简单句；中文单句宜短，过长则重读是否仍清楚  
- 只有表无段 → 表前补判断段，表后补读法段  

## 7. 标点与中英文（摘要）

- 中文句子用全角标点；标题末不加句号  
- 中文与半角英文/数字之间按全文统一空格习惯（报告优先：中英之间一空格）  
- 数字与单位：`pcu/h`、`km/h` 等保持领域习惯；范围可用 `～`  
- 图表编号用半角连字符：`图 3-1`
