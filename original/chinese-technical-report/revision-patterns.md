# 修订模式（通用）

写新节或改旧节时按需查阅；不替代 `structure-and-figures.md`。

## 1. 正文真源唯一

| 规则 | 做法 |
| --- | --- |
| 单一真源 | 选定一种格式作正文真源（常见为 Markdown）；导出物（Word/PDF）由真源生成 |
| 不平行定稿 | 不另留易与真源节号/图号错位的「第二份定稿」 |
| 改前对文件 | 用户说「某节」时，先在**真源文件**里确认节是否存在；别稿有而真源无 → 先对齐再改，**不臆造** |
| 改完回写 | 只改真源；需要交付 Word/PDF 时再导出 |

## 2. 节名与节内同名展开

- 节标题用完整中文议题名，忌口语、切口、开发黑话。
- **改节名后**：中心段、表题、文内称谓用**同一名称**展开，不残留旧题口径。
- 标题只标议题，不写结论。

## 3. 节契约：名实相符、有证据才立节

立节或改节名时，除「五问」外再核：

| 检查项 | 通过标准 |
| --- | --- |
| 节名所承诺的议题 | 正文确实在讲该议题 |
| 证据 | 有可核真源（数据、实验、规范条款、双次运行等） |
| 未做工作 | **不**用未做内容占节名；也不写成长段「本文未另做××」当节主体 |

| 不宜 | 宜 |
| --- | --- |
| 「一致性与敏感性」（却无敏感性实验） | 有证据的议题名（如「结果复现一致性」） |
| 「可复现信息与证据范围」式清单堆砌 | 「结果」：先讲结果如何组织，再举 **1** 例落到字段与数字 |
| 验收旁白当节名 | 能力/措施类议题名 → 证据表 → 成效指向正式对照章 |

## 4. 「结果组织」与「复现」分节写

- **结果**：用短表说明结构化层次（输入/输出/对照/结论等）；举 1 例，数字与后文主表同口径。
- **复现一致性**：同一条件、同一对象下的**两次独立运行（或两次独立计算）**；表列关键指标是否一致；正文主表取一次，另一次作复验并回指。
- 别案、验收样例与主对照**分列**，不混进同一复现表。
- 写不出两次可比证据，就不写「已复现一致」。

## 5. 插图替换清单（一次换齐）

1. 图文件入库（路径稳定）
2. 图题与引入段（判断 → 见图）
3. 本章证据索引表（若有）
4. 文内区间回指（如「见图 3-2～图 3-5」）及他章同类回指

**角色变了就重编号**：避免「图题说 A、画面是 B」。

**图题括号**：

| 宜保留 | 宜去掉 |
| --- | --- |
| 标识对象的案号/方案号 | 阅读元信息（如「界面截图」）——节题或正文已说明载体时 |

## 6. 数字与证据包对齐

- 关键数字以约定真源（结果包、实验记录、规范表）为准。
- 改一处身份或成效数字时，摘要、方法章、结果章、结论**同口径扫一遍**。

## 7. 修订自检

- [ ] 改的是正文真源，未误改过期导出副本
- [ ] 节名与节内称谓一致；未做工作未占节名
- [ ] 新图/换图：文件、图题、引入、索引、区间回指已齐
- [ ] 复现类主张有两次可比证据
